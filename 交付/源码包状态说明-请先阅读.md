# 交付源码包状态说明（请先阅读）

`交付/` 下的 `基于视频感知的隧道交通数字孪生系统源码包/` 目录和同名 `.zip` 是 **2026-10-18 缺陷审计修复批次之前的旧快照**，不是当前主干的最新代码。

旧快照至少包含以下已修复的缺陷（对应审计条目）：

- `backend/calibration/homography.py` — M1：斜向的合法顺时针凸四边形会被拒绝
- `frontend/src/components/CalibrationPanel.tsx` — M2：宽/长字段与画面方向绑定，横向道路易填反
- `frontend/src/api.ts`、`frontend/src/App.tsx` — L1：先解析 JSON 再判断响应状态，纯文本错误不可读
- `backend/vision/video_reader.py` — L2：帧数为 0 或偏大时定位失败
- `backend/service.py` — L3：实时流路径会调用 seek
- `backend/main.py` — L4：导入/上传异常时临时文件可能残留
- `backend/camera_templates.py` — L5：模板缺少场景键时返回 500
- `frontend/src/components/DigitalTwin.tsx` — L7：旧版 Canvas 没有 `roundRect`

此外，该快照也早于 `BUG_REPORT.md` 中记录的前一批修复。

**请勿直接使用该目录或 zip 作为交付物。** 交付时请从修复后的 `main`（或对应 PR 合并后的提交）重新生成源码包，并重新运行 `pytest`、`npm --prefix frontend test`、`npm --prefix frontend run build`。该旧包本次仅保留作历史归档，未删除。
