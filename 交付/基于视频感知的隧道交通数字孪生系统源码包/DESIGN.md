# 中文交通监测工作台设计规范

来源为 awesome-design-md 社区整理的 Linear 页面分析，非 Linear 官方规范。本文保留其表面层级、细边框与克制主色，将营销字号和留白改为交通仪表盘密度。项目沿用 React、TypeScript、ECharts、原生 CSS 与现有业务逻辑。

项目采用用户明确选择的浅色暖调：奶油米白背景、浅杏色提升表面与琥珀色主要操作，保留交通绿色和红黄报警语义。该约定优先于来源的黑色背景与紫蓝主色，保留 Linear 的组件层级与排版原则。

## 项目约定

- 视频与孪生是主要操作区域，核心指标先于分析明细；保留侧栏导航、收起状态与分区锚点。
- 中文用系统字体与苹方 / 微软雅黑，不下载专有字体。标签、数据单位与错误提示均须可读。
- 保留检测、同帧解码、坐标映射、标定、车道、统计段、模型参数、模板、证据复核和导出流程。未标定不得显示真实速度。

## 视觉令牌

CSS 的 `:root` 为颜色与字体的唯一来源；ECharts 和 canvas 从 `readVisualTheme()` 读取。新增界面不用单独的硬编码色。

| CSS 变量 | 值 | 使用范围 |
| --- | --- | --- |
| `--bg` | `#f7f0e3` | 页面、视频留边 |
| `--surface` | `#fffaf0` | 面板、侧栏 |
| `--surface-raised` | `#efe2ca` | 表头、弹窗、嵌套容器 |
| `--surface-hover` | `#e8d6b7` | 悬停、当前导航 |
| `--border` | `#d8c5a7` | 1px 分隔线 |
| `--border-strong` | `#8b7054` | 控件和强调边界 |
| `--text` | `#372a20` | 标题、主要数据 |
| `--muted` | `#594637` | 正文、表格 |
| `--subtle` | `#72583e` | 图表刻度、辅助信息 |
| `--primary` | `#995c1d` | 主要操作背景 |
| `--primary-hover` | `#80460f` | 主按钮悬停，配白色文字 |
| `--accent` | `#87461b` | 链接、焦点、导航指示 |
| `--success` | `#3e6743` | 在线、已标定、正常运行 |
| `--warning` | `#87500b` | 未标定、尺度确认、计数线 |
| `--danger` | `#a13029` | 异常、失败、破坏性操作 |

琥珀色用于操作与定位；统计卡片保持中性色。报警必须同时有图标或文字。车辆类别和多条图表曲线可使用分类色与虚实线，不改变报警颜色，也不把分类色当作装饰。

## 字体与密度

| 元素 | 桌面 / 手机字号 | 字重与行高 |
| --- | --- | --- |
| 页面标题 | 28 / 24px | 600，1.3，中文轻微负字距 |
| 分区标题 | 16px | 600，1.5 |
| 面板标题 | 14px | 500，1.5 |
| 指标数字 | 34 / 30px | 500，1.15，等宽数字 |
| 表格、表单、按钮 | 13 / 12–13px | 400–500，1.5–1.7 |
| 辅助文字 | 12px | 400，1.6 |
| 图表刻度与画布标签 | 11–12px | 高对比，避免重复标签相互覆盖 |

ID、时间、FPS 使用等宽字体；中文说明用普通文本字体。数据不靠缩小字号解决溢出。中文段落不采用营销页面的极端负字距。

## 组件规则

- 间距以 4px 为基准：控件间 8–12px，网格 16px，面板内 16–20px，章节 24px。桌面内容最大 1480px。圆角：标签 4px、控件 8px、面板 12px。
- 侧栏：默认显示图标和中文标题，当前位置通过表面提升、指示线与 `aria-current` 呈现；工具与内容导航分组。中小屏压缩，菜单区域可单独滚动，底部操作不遮挡菜单。
- 视频 / 孪生：暖灰棕细边框，画布不裁切、不改变比例或坐标。桌面并列；手机上下排列。标题、坐标信息、进度和编辑提示各有固定区域。
- 统计卡片：标签、数值、说明的基线一致，不给每张卡片不同装饰色。异常数仅在实际存在报警时强调红色。
- 图表：同一字体、刻度颜色、提示框样式；图例换行时为绘图区预留高度。速度轴带单位，缺失数据保持空缺，预测量用虚线区分。没有数据时显示明确提示。
- 表格：粘性表头、清楚的行分隔、轻微 hover；列标题不折断，数值等宽。手机允许表格内部横向滚动，不允许整页横向溢出。
- 按钮：主按钮琥珀色实底、次按钮中性表面、三级操作文本。完整提供 hover、pressed、focus-visible、disabled 和 busy；触屏及 ≤1100px 按钮 / 输入至少 44px；桌面主次按钮至少 40px，内联文本操作至少 32px。
- 弹窗：半透明暖棕遮罩、浅杏色提升表面、有限宽度与视口内高度。标题区保留关闭入口；长内容内部滚动；保留对话框语义、Escape、焦点约束和恢复、背景隔离、忙碌状态与内部错误。
- 设置、模板、报告、证据复核同用这些令牌；危险确认用红色或琥珀提示，不沿用旧绿灰色块。

## 响应式与验收

- ≥1200px：四列指标、双监测画布；图表随可用内容宽度调整列数。侧栏在 >1100px 支持展开 / 收起。
- 681–1199px：两列指标，设置面板移到监测区域下方；≤1100px 使用紧凑侧栏。
- ≤680px：两列指标、单列画布 / 图表 / 导出；控件可换行，时间轴单独一行。
- 检查 1440px 桌面、1024px 平板、390px 手机，并补查 320px 窄屏与短高度。实际截图必须覆盖有数据状态、表格、导入弹窗与设置 / 模板。
- 检查整页溢出、控件遮挡、图例 / 刻度、键盘导航、弹窗滚动。小文字与背景对比度至少 4.5:1，图表关键线条至少 3:1；尊重减少动态效果偏好。
- 运行 `npm --prefix frontend test` 和 `npm --prefix frontend run build`；如果改动业务逻辑，补充相应回归。本次只调整呈现与交互可用性。
