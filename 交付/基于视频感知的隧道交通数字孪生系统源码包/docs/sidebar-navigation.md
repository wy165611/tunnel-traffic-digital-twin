# 工作台导航检查

日期：2026-10-01。沿用 React、TypeScript、原生 CSS 和现有图标库，无新增依赖。本次调整前端导航、分区定位和导出入口。

## 使用方式

- 工作区六个入口定位页面内容：监测总览、感知与孪生、交通分析、事件记录、车辆明细、数据导出。滚动时同步高亮；点击后 URL 保留分区锚点，支持浏览器返回。
- 视频管理打开现有导入窗口；道路标定和分析参数打开编辑面板并定位相应区域，分析中会先暂停。切换两种工具不会清空尚未完成的绘制草稿。
- 底部按钮开始或暂停分析；加载模型、未选择视频或正在编辑道路时禁止启动。车辆和事件数字来自当前分析快照。
- 桌面支持展开/收起并本地保存偏好；平板和手机自动紧凑显示；短窗口菜单独立滚动。
- 数据导出区使用现有下载 API，提供车辆、交通统计、事件三种 CSV。尚未创建统计段时显示开始分析入口；无事件时事件文件仍包含表头，未标定真实速度保持空白。

## 验证结果

- `npm --prefix frontend run build` 通过 TypeScript 检查及 Vite 生产构建。原有 ECharts 大分包提示仍存在。
- `npm --prefix frontend test`：8 项几何测试通过。
- 在 `http://127.0.0.1:8000` 的实际生产页面检查六个入口的锚点、焦点、选中状态和内容可见性，滚动高亮及浏览器返回均通过。
- 收起后导航宽 80px、展开后宽 196px，刷新保留收起偏好。
- 视频管理对话框阻止背景交互，Escape 关闭后焦点回到侧栏入口。
- 分析参数与道路标定定位正确；绘制 1/4 个标定点后反复切换工具，草稿保留；编辑时侧栏启动按钮禁用，关闭时取消草稿。本次验证未保存新的道路配置。
- 实际下载交通统计 CSV：256 行数据，最后一行当前车辆 8、累计过线数 19，与页面结果一致，未标定速度字段为空。
- 在独立临时数据目录、8002 端口运行内置真实视频，验证导出空状态启动分析，以及侧栏暂停/继续。继续时保留同一 run_id，帧数递增。未重建用户 8000 服务上的统计段。
- 1024×900、390×844、320×720 和 1440×600 检查：无整体横向溢出，导出区和分析设置适配，键盘 Enter 可打开设置并定位焦点，短窗口工具菜单可滚动，底部控制始终可见。遵循减少动态效果偏好。
- 浏览器页面未发现运行异常。
