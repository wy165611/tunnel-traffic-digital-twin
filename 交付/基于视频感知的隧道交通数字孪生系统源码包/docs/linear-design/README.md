## 修复与检查

- 四种视口整页宽度分别为 1440、1024、390、320px，没有整页横向溢出。桌面四列指标，中小屏两列；手机画布与图表单列。
- 修复来源栏在手机纵向 flex 中把桌面 280px 横向基准变成高度的问题；来源信息、标定状态和播放状态正常换行。
- 视频保持原始比例，孪生保持现有像素/米制映射；车辆标签在视口内避让，密集标签保留对应引线，未改变车辆、轨迹与计数线的位置。
- 桌面主要操作约 40px，平板及手机主要操作/输入至少 44px。窄屏主操作换行，侧栏菜单独立滚动，底部分析入口可达。
- 手机车辆表格只在自身容器横向滚动。实际横向操作后 `scrollLeft=135.5`，状态列与“未标定 / 待估计”可读，整页宽度保持 390px。
- 导入、模板和报告弹窗长内容内部滚动；固定标题区保留关闭入口。验证 Tab/Shift+Tab 约束、Escape、返回入口焦点、忙碌控件失焦后的恢复及导入失败提示。导入和模板在背景解除 `inert` 后恢复焦点。
- 参数入口聚焦并直接显示参数区域；修复平滑分区滚动与参数定位竞争导致参数标题落在视口底部的问题。手机参数标题实测距顶约 24px。
- ECharts 图例、刻度、单位、分类图和空值语义检查通过；已确认 CSS 主题与视频/孪生/ECharts 共用颜色来源。普通小文字令牌最小对比度 4.57:1、主按钮文字 5.38:1、控件边界最小 3.24:1。禁用控件与装饰分隔线不计入这些阈值。

## 运行与前端检查

- `npm --prefix frontend test`：31 passed，0 failed。包含既有 27 项业务/几何/快照回归，以及主题对比度和密集标签边界的 4 项新增检查。
- `npm --prefix frontend run build`：TypeScript 和 Vite 生产构建通过。ECharts 分块约 545 KB，构建仍有超过 500 KB 的体积提示；没有构建错误。
- 真实演示视频完成 256 帧分析；最终界面包含 18 个趋势采样点、28 辆累计识别、19 次累计过线和 8 个在场轨迹，其中末帧是预测位置。报告、车辆明细、车道窗口与模板预览正常显示；无尺度标定时真实速度保持不可用。
- 浏览器验证使用临时 `TWIN_DATA_DIR`，视频和模型只读复用，分析文件与验收模板写入临时目录，没有覆盖用户原有运行记录、道路配置或模型设置。

此次证据验证界面和功能连续性，不代表真实隧道精度、检测准确率或测速精度；后端测量、事件规则、源视频及导出契约未改动。
