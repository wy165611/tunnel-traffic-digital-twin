# 前端界面检查记录

日期：2026-10-01。使用 redesign-existing-projects 技能，沿用 React 19、TypeScript、Vite 6、ECharts 6 和原生 CSS。没有增加依赖、迁移技术栈、接入远程字体或修改后端算法。

## 检查发现与改进

| 范围 | 原有问题 | 本次调整 |
| --- | --- | --- |
| 字体 | 辅助信息大量使用 8–10px，标题与数据层级偏弱 | 中文使用本机苹方，拉丁文字优先 Avenir Next；主要正文 12–13px，标题 24–34px，指标 30–36px，数字使用等宽字体或表格数字 |
| 配色 | 冷蓝底色与多个亮色同时强调，辅助文字对比度偏低 | 统一绿灰表面与柔和青绿主色，提高辅助文字对比度；车辆类别保留区分色，警告保留语义色 |
| 层级与间距 | 指标位于大画布下方，各面板权重相近、间距紧凑 | 核心指标前置，当前车辆重点突出，添加三组分区标题，统一面板内边距与章节留白 |
| 响应式 | 窄屏依然并排显示双画布，表格信息密集 | 手机上下显示两个画布、两列指标，播放器进度换行，表格独立滚动；标定面板在平板转为下方布局 |
| 交互 | 按压与键盘焦点不足，输入框焦点被移除，侧栏仅有图标 | 增加 hover、按压、focus-visible、导航文字、当前状态与跳转内容链接；尊重减少动态效果设置 |
| 数据空状态 | 图表空白，表格和视频仅有简单提示，连接失败缺少重试入口 | 增加图表、表格、视频空状态与连接重试，连接时显示骨架占位 |
| 导入弹窗 | 缺少对话框语义、焦点约束、Escape 关闭；错误显示在遮罩背后 | 弹窗内错误、焦点循环与恢复、背景 inert、键盘关闭、短屏滚动；忙碌时禁用关闭与输入 |
| 内容与品牌 | DEMO MODE 固定显示，英文辅助标签较多，无 favicon | 改为准确的“本地运行”，辅助标签中文化，增加隧道轮廓品牌标记和 SVG favicon |
| 样式组织 | 样式压缩在一行，主题色、间距和层级分散 | 将 CSS 展开，集中主题色、圆角、等宽字体与 z-index 变量；保留 canvas 内的数据绘制逻辑 |

项目是本机单页分析工作台，未新增账号、隐私/条款页面、营销区块、Cookie 弹窗或路由。保留既有图标依赖，以自定义隧道图形区分品牌。

## 验证

- `npm --prefix frontend run build`：TypeScript 与 Vite 生产构建通过。ECharts 分包仍有原有的 500kB 提示，不影响构建成功。
- `.venv/bin/python -m pytest -q`：24 项通过，包含算法、几何、规则、上传、路径导入、HTTP / WebSocket、标定、暂停继续、拖动、新统计段及 CSV。
- 使用真实内置演示视频进行浏览器检查：开始分析、暂停、重新分析、0.5× / 1×、键盘进度跳转；确认车辆数、流量、曲线、分类、表格与车道统计实际更新；车辆 CSV 实际下载成功，包含表头与分析数据。
- 在道路标定面板绘制两个计数线端点，确认绘制完成后保存按钮恢复可用；关闭面板取消草稿，未覆盖原道路配置。
- 路径导入错误直接显示在对话框内，错误后仍可编辑；Shift+Tab / Tab 在首尾控件循环，Escape 关闭，焦点回到触发入口。
- 1280px 桌面、1024px 平板、390px 手机和 320px 窄屏检查通过，页面没有整体横向溢出；平板标定面板与双画布布局正确。
- 在后端提供的 `http://127.0.0.1:8000` 上验证最新生产页面，浏览器控制台未发现前端运行异常。
