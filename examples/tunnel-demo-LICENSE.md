# 示例视频来源与许可

- 文件名：`tunnel-demo.mp4`
- 原始作品：`The Rantatunneli of Tampere.webm`（芬兰坦佩雷隧道）
- 来源页面：https://commons.wikimedia.org/wiki/File:The_Rantatunneli_of_Tampere.webm
- 作者：Sounds of Changes / Työväenmuseo Werstas / 拍摄与录音 Mikael Maffei
- 许可：Creative Commons Attribution 3.0（CC BY 3.0）
  https://creativecommons.org/licenses/by/3.0/
- 本包修改：截取原视频第 3–23 秒，缩放为 960×540、25 fps、H.264，移除音轨，文件名改为 `tunnel-demo.mp4`。

该视频仅用于演示软件的车辆检测、跟踪与统计流程。视频中的道路、车辆和场景与软件作者无关。
