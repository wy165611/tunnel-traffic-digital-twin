# 分析报告、车道窗口与报警证据复核

本功能服务于本机录制视频分析，使用原有 FastAPI、React、ECharts 和预训练检测器。提供的真实演示素材是桥梁俯拍视频，不能据此宣称已在隧道完成验证，也不提供自动生成的速度真值或准确率。

## 使用入口

1. 选择视频并开始分析。在“数据导出”点击“阅读当前分析报告 / 对照”，或展开历史统计段读取旧报告。分析中点击刷新会读取当时完成帧的一致快照。
2. 报告提供实际分析起止时间、累计过线、机器报警分型、观测速样本均值/极值/覆盖，以及有界降采样趋势。可打开可打印页面保存 PDF，或下载可离线打开的 HTML；HTML 内含静态 SVG 趋势。
3. 选择另一段对照。只有视频内容身份相同、起止时间差在 0.1 秒以内、计数线、车道及尺度标定相同时，标记为可比较。模型、检测/跟踪/速度/规则与道路方向参数差异另行展示。输出变化不表示准确率提升。
4. “运行明细”下方可选 10、30、60 秒车道窗口，查看观测/预测车辆、窗口过线、覆盖秒数、累计过线和观測均速；报告也可读取历史车道趋势。
5. 当前报警或报告内历史报警点击“证据 / 复核”，查看触发截图、规则、标定及观测轨迹，并用独立播放器复查原视频。选择待复核、确认报警或误报，填写最多 1000 字备注并保存。

## 统计定义与边界

- 累计过线取 `traffic_statistics.csv` 的累计 `flow` 列最大值；逐帧累计值不会求和。同一跟踪 ID 仅计一次过线，与现有计数规则一致。
- 报告速度只统计 `vehicles.csv` 中 `observed=true` 且速度有限的车辆帧样本。均值不是每车平均速度。覆盖率为有效速度样本 / 实际观测车辆帧样本；预测位置排除。旧 CSV 缺少 observed 时，此统计不可用。
- 未完成实测 Homography 标定时，世界坐标、真实速度、加速度以及速度相关报警保持空值/关闭。时间占有率仍未启用。
- 车道窗口采用视频时间 `(t−window, t]`，左边界的过线不包含在内。覆盖时间为 `min(window, t−segment_start)`；不足窗口明确显示“不完整”，不把短时实际计数外推为完整分钟。
- 车道采样间隔不小于 0.5 秒；每次保存三个窗口。未分配车道单列“未划分”。预测车辆只显示数量，不计入窗口流量或速度。
- 实时历史最多保留 600 个采样点；报告流式扫描 CSV，不整体读入长视频数据。全局趋势最多 300 点；每个车道每种窗口分别最多 300 点，保留起止端点。报告内事件摘要最多 200 条，完整事件由分页接口读取。
- 文件缺失、空数据及旧段元数据缺失不会制造累计计数、速度、区间或来源；界面提示不可用。CSV 输出继续防止公式注入，新事件与车道文件的 `lane_json` 保存原名供历史展示，包含真实 apostrophe 的名字不会被盲目剥离。

## 证据与复核

触发报警时，在统计段内生成稳定 `event_id`，先将 JPEG 和不可变 `capture.json` 放入临时目录，完成后原子改名。JPEG 仅画当时实际观测目标框，框坐标由原视频尺度转换为实际缩小帧尺度。元数据保存统计段/事件 ID、视频内容身份、触发时间与帧、原始/展示尺寸、车辆事实、观测轨迹、规则参数与标定。

人工记录保存于独立 `reviews.json`，用锁保护读写并原子替换。它不会修改 `events.csv`、截图、机器报警数量或测量结果。状态确认只是人工复核结论，仍不是完整人工真值数据集。

独立原视频播放器使用证据保存的来源 ID，仅允许 `DATA/videos` 内的文件，并在播放前核验内容哈希；缺失、身份未知或内容改变时禁止回放，截图仍可查看。提供 HTTP Range，浏览器定位事件前约 5 秒并在后约 5 秒暂停；原视频没有检测叠加。浏览器不支持某个原格式时提示失败，不做整段转码。查看/保存证据不会调用实时 seek、选择视频或重新分析。

## 存储与接口

- `backend/reports.py`：有效统计段 ID、锁内快照读取、流式汇总、条件对照、转义的 HTML/SVG 打印页面。
- `backend/evidence.py`：原子截图事实、来源核验、分页事件与独立复核记录。
- `backend/exporter.py` / `backend/processor.py`：整帧锁及所有 CSV/元数据的一致快照，新增 `lane_statistics.csv`。原三种 CSV 保持兼容，事件 CSV 追加 ID 与原车道名称信息。
- `frontend/src/components/ReportDialog.tsx` / `LaneTrends.tsx` / `EvidenceDialog.tsx`：报告、窗口和复核入口。弹窗沿用 Escape、焦点陷阱/恢复与滚动锁，图表跟随容器调整尺寸。

主要 API：

| 请求 | 用途 |
| --- | --- |
| `GET /api/runs/{run}/report` | 结构化报告 |
| `GET /api/runs/{run}/report.html?download=true` | 下载可打印 HTML |
| `GET /api/runs/{run}/compare/{other}` | 可比条件与配置差异 |
| `GET /api/runs/{run}/events?offset=0&limit=50` | 历史事件分页 |
| `GET /api/runs/{run}/events/{event}` | 证据事实与人工记录 |
| `GET .../{event}/screenshot` / `source` | JPEG 与核验后的独立原视频 |
| `POST .../{event}/review` | `{status: pending|confirmed|false_positive, note}` |
| `GET /api/export/{run}/lane_statistics` | 新增车道 CSV |

## 自动化验证

`tests/test_analysis_features.py` 使用临时视频和确定性检测框，通过现有跟踪器、实测尺度映射及真实规则触发异常停车，验证缩小帧截图、完整事件接口、Range、复核持久化、来源内容改变以及实时状态保持。另验证累计值不求和、观测与预测分离、未标定速度为空、旧数据不可用、窗口边界/起点、按窗口降采样保留端点、CSV 特殊车道名称、无效 ID 与复核输入，以及帧锁阻止半帧报告。

`frontend/tests/analysisData.test.mjs` 验证车道窗口/车道过滤保留空速度和预测独立序列、事件片段边界，以及报告/证据/保存旧响应不会替换新目标。完整后端测试、前端测试、生产构建与独立运行时检查用于回归现有功能。实际浏览器与真实视频验证记录由交付时的独立评审补充；这些测试不证明真实交通检测准确率。
